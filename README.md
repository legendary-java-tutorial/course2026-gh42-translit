# translit

[![ci](https://github.com/legendary-java-tutorial/course2026-gh42-translit/actions/workflows/ci.yml/badge.svg)](https://github.com/legendary-java-tutorial/course2026-gh42-translit/actions/workflows/ci.yml)

Тесты запускаются на каждый Pull Request — ещё до слияния.

## Как проверить

```
npm install
npm test
```
